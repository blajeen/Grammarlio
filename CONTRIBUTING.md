# Contribuindo / Contributing

Obrigado por ajudar a tornar a revisão de textos acessível. Issues e pull requests em português ou inglês são bem-vindos.

1. Use Node.js 22+, execute `npm ci` e `npm run check`.
2. Para regras, inclua um exemplo incorreto e exemplos corretos que não devem disparar a regra. Preserve posições Unicode e evite correções amplas que mudem o sentido.
3. Para alterações na integração com páginas, teste campos comuns e a proteção contra edições antigas. Não adicione coleta contínua ou transmissão de texto.
4. Documente origem, licença e atribuição de dicionários, dados ou modelos adicionados. Nunca copie bases proprietárias.
5. Faça alterações pequenas e explique comportamento, limitações e testes no pull request.

Do not include private user text in bug reports. For security-sensitive reports, use GitHub private vulnerability reporting if enabled rather than publishing exploit details or personal data.

Future work includes broader language coverage, full English interface translation, editor integrations and local AI evaluation. Features must remain usable without a Grammarlio account or subscription.
